# AI Assistant, Engine & Schematic Printer (`autismclient.ai.*`)

AUTISM Client's autonomous AI stack spans **337** Java classes (**255,259** LOC) across three packages (`autismclient.ai`, `autismclient.ai.engine`, `autismclient.ai.print`) plus the bundled Rhino script worker (`src/main/resources/autism-ai/worker.jar`, untouched). Alongside `24` pre-existing readable classes (`12` in `ai`, `12` in `ai.engine`), **Phase 7A–7E** renamed **312 / 313** obfuscated AI classes (`34` in `ai.print`, `59` in `ai.engine`, `219` in `ai`: `308` matched verbatim to `source-contracts.json` plus `4` source-inferred helpers `AiParkourFallWarning`, `AiPanelWrapJump`, `AiActedOperation`, and `AiPerfMetrics`) and **Phase 8B** moved `ai.a` → `ai.engine` and `ai.b` → `ai.print`, bringing AI readability to **336 / 337** (`100%` of renameable AI classes; only compile-time ABI-pinned `autismclient/ai/aP` remains obfuscated).
